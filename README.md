\# Moving Company Booking \& Management System



A complete management system for managing staff, registered vans,

ands stock for a moving company.



\## Features

* AED for staff, vans, van maintenance, and the various stock for vehicle repair.
* Staff Search \& Filtering
* Staff Viewer - ID, name, Telephone Number, Job Role
* Van Search \& Filtering
* Van Viewer - ID, Registration Number, MOT due date, Model, Color, Size
* Notification Pop up - Vans Due For MOT; Includes ID and Registration Number
* Van Maintenance Search \& Filtering
* Maintenance Viewer - Includes details of the van of repair, maintenance description, as well as related driver and mechanic.
* Maintenance Report Generator
* Maintenance Cost Calculator - Select a Maintenance, Enter Stock required for maintenance. Includes a list of the quantity of each item currently in stock.
* Daily, weekly, monthly \& yearly report generator - Maintenance, Staff Training, Item Orders
* Reports can be printed
* Mailbox Feature - displays any upcoming training for logged in staff \& maintenances to be done.
* Stock Viewer - ID, total orders placed, name, quantity, threshold, price, stock type.
* Order Stock - Order quantity of Stock.
* Update Order Status - Can Update order details.
* Report Order Discrepancies - Eg. Missing Items
* Display delivered / undelivered orders
* Generate Order Report
* Order Discrepancy Viewer - Can view all items with discrepancies, can update if discrepancy has been resolved.
* Order Discrepancy report generator
* Login System - Mechanic, Driver, Manager; Select user from registered Staff
